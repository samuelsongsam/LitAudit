# 连续对话真实验收（2026-11-07）

## 测试方式

经用户明确许可，仅将公开来源的题录、摘要、开放全文和新生成测试对话发送至配置的 DeepSeek。
通过真实本地 `/api/chat` 连续发问，不使用模拟模型，不复制用户聊天、笔记或人工记录。
原研究及金标数据不修改。语义地图不是本次验收对象，测试副本明确标注地图不可用。

## 发现与修复

- 普通上下文原来每条截断为1500字且丢失引用结构；现在保留最近6条、每条最多6000字，并携带讨论论文范围。
- 工具规划原来未收到聊天上下文；现在同时收到最近讨论与结构化引用。
- “这些方案”会扩大到全研究；“后一篇”的序号又可能按引用频次排序。现按最终回答显示顺序保存范围并解析指代。
- 补证回答可能换成工具没有处理的论文；现绑定实际获取/检索的论文。
- 不使用query的工具收到多余说明会中断；现忽略无副作用的多余query，未知工具和跨范围ID仍拒绝。
- 规划器JSON解析不一致；复用项目JSON解析器，格式错误最多修订一次，仍计入四次调用上限。
- 新子进程冷启动语义重排可能耗尽90秒；补证工具采用明确标注的BM25，常规阅读的语义重排不变。
- 获取不到开放全文时原来仍显示“补证完成”；现标明尚无正文依据。
- 请求两个研究问题时原来固定最多四个；现按请求限制为两个。

## 实测结果

- 完整六轮：总结、两篇比较、同条件吞吐追问、后一篇指代、全文补证、两个研究问题。
- 最终上下文专项三轮：比较范围为 paper-012、paper-013；“这些方案”保持两篇，“后一篇”只引用 paper-013。
- 最终补证专项：读取摘要、获取全文、BM25搜索均完成，检索8个片段，回答引用 paper-012 的第9和11页，整轮约82秒（含回答及复核）。
- 全量离线回归592项通过；后续针对性回归64项通过；前端质量回归12项通过。
- 真实测试也出现公开全文不可用、工具预算耗尽等情况；不将这些降级结果当作全文获取成功。
